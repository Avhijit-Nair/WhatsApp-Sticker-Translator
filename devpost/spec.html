Sticker Translator: Technical Spec

A native Swift Mac app built only from Apple's on-device frameworks. No downloads, no API keys, and nothing leaves the Mac.

How this works, in plain language

  1. Control panel: toggle + status. Hides to the menu bar.
  2. Window watcher (ScreenCaptureKit): snapshots only the WhatsApp window about 3× per second.
  3. Text finder (Vision + NaturalLanguage): reads text and positions, groups lines into "stickers," and keeps only the Spanish ones.
  4. Translator (Foundation Models): Apple's on-device AI writes the literal translation + meaning, once per sticker, saved in a cache.
  5. Tooltip overlay: small dark floating windows that move to wherever the text is in each snapshot and hide when it's gone.

Re-scan, don't track: the app looks again a few times per second instead of following each sticker. It's simple and survives scrolling. Tooltips trail slightly behind fast scrolls (accepted).

Run, risks, and decisions

Where it runs and how someone tries it

./scripts/run.sh → grant Screen & System Audio Recording in System Settings → relaunch. It runs locally on your M4 Air with Apple Intelligence on.

Demo: staged Spanish-sticker chat (text messages in English). Toggle on → sticker arrives → Translating… → literal + meaning → scroll → ✕ → optionally Wi-Fi off. Submission is the video + public repo. No deployment and no downloadable app.

Important failure modes
  • Permission lost after rebuild (ad hoc signature) → re-grant; or sign with a free Xcode certificate
  • Model refuses, errors, or is slow → error + Retry; "Translating…" while waiting
  • Stylized fonts misread, or short text misjudged → tune using DevCheck + samples
  • Spanish text message on screen → gets a tooltip too (known limitation)
What was simplified
  • Any Spanish text = sticker (stretch: check WhatsApp's layout via accessibility info)
  • Re-scan at ~3 fps instead of motion tracking
  • One state per unique text; identical stickers share it
  • In-memory only; local run + video
Decisions and early checks
  • You chose: native Swift + Apple on-device frameworks; Spanish only in stickers for the demo; the re-scan tradeoff; local + video
  • Verified on your Mac: Foundation Models available; Vision es-ES supported (no Hindi); WhatsApp bundle ID net.whatsapp.WhatsApp
  • Build step 1: test explanation quality on 3–5 sample slang stickers before building the overlay
  • Verify early: ScreenCaptureKit captures WhatsApp normally; Vision handles sticker fonts
